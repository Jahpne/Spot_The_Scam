Model benchmark

Measures four ways of judging a message on the labelled test sets, using the real model in this browser: Rules (no AI), AI (fixed 4 examples), AI + DB (examples retrieved from the database), and Hybrid (rules combined with AI + DB). Nothing here is made up: every number comes from running the model on this page.

Sets. Game cards were used to build the rules, so they are not an independent test. Held-out was written before the rules. Stress was written to break the rules. Retrieval skips any database row that is almost identical to the test message (similarity 0.95 or more) so it cannot cheat. "Unsure" counts as wrong in accuracy. "Scams called real" is the dangerous mistake.
